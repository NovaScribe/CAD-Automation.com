How to use this CATIA macro

  1. Download the macro. Accept the Terms and Conditions when prompted, then save the .catvba file somewhere you can access easily.
  2. Open CATIA V5. Open the CATPart or CATProduct that the macro should work on. Save a backup before running a macro that changes geometry, structure, or file visibility.
  3. Open the macro dialog. In CATIA, select Tools > Macro > Macros.
  4. Load the downloaded file. Choose Macro libraries, select Files of type: All files if needed, browse to the downloaded .catvba file, and add it to the library list.
  5. Run the macro. Select the macro library, click Show contents if required, choose the available procedure, and click Run. Follow any prompts shown by the macro.
  6. Check and save the result. Review the changes in CATIA, then save your document only after confirming that the result is correct.
Before you run it: Macros can modify your active CATIA document. Use a copy of important files and verify that the macro is compatible with your CATIA V5 environment.
